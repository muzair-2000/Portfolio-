## 🛠️ Deployment on GitHub Pages

1. Create a new repository on GitHub
2. Push this folder's contents to the repository
3. Go to **Settings → Pages**
4. Under **Source**, select **Deploy from a branch**
5. Select `main` branch and `/ (root)` folder
6. Click **Save** — your site will be live in a few minutes!

## 📝 Customization

- **Contact Info**: Update email, phone, and location in `index.html`
- **CV/Resume**: Add your PDF resume and update the download link in `index.html`
- **Social Links**: Update LinkedIn, GitHub, and Twitter links in the footer
- **Projects**: Replace project images in `assets/images/` and update descriptions
